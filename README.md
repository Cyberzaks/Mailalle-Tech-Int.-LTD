# Mailalle Tech International Limited

A simple static website for Mailalle Tech International Limited, created as a business profile and contact page for the company.

## Project Overview

This project includes a three-page website:

- Home page
- About page
- Contact page

The site presents the company's mission, services, and a basic contact form for visitors to reach out.

## Project Structure

```text
FlexiSAF Internship/
├── index.html
├── about.html
├── contact.html
├── README.md
```

## Features

- Clean multi-page layout
- Company information and service overview
- About section with mission and vision
- Contact form for user inquiries
- No build tools or package installation required

## How to Run

Because this is a static HTML project, you can view it in two easy ways:

### Option 1: Open directly in a browser

- Open the `index.html` file in your browser.
- You can also navigate to the `about.html` and `contact.html` pages from the website menu.

### Option 2: Run a local server

From the project folder, run:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
